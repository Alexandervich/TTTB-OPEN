PREREQUISITES

node_modules/ and dist/ are not stored in git (see .gitignore).
After cloning, restore them as follows.

1. Install Node.js
   Install a current Node.js LTS release (includes npm).

2. Install dependencies
   npm install
   This recreates node_modules/ (including Electron) from package.json
   and package-lock.json.

3. Run
   npm run dev       Vite dev server
   npm start         Build, then run the server
   npm run desktop   Build, then launch the Electron app
   npm run dist      Build and package a Windows installer (electron-builder)
   npm run server    Run the server only (requires "npm run build" first)

NOTES
- dist/ is generated by "vite build". start, desktop and dist build it
  automatically.
- "npm run server" serves static files from dist/, so run "npm run build"
  once beforehand.
- server/data/tttb.db (the database) is tracked and comes with the clone.
